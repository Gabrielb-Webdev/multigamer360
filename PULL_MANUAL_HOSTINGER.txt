# Instrucciones para actualizar manualmente en Hostinger

Si el webhook no funciona o quieres actualizar inmediatamente:

## Vía SSH:
```bash
# Conectar a Hostinger
ssh u123456789@teal-fish-507993.hostingersite.com

# Ir al directorio
cd domains/teal-fish-507993.hostingersite.com/public_html

# Hacer pull
git pull origin main

# Verificar versión
head -n 6 admin/ajax/search_game_multi.php
# Debe decir: Version: 2.3

# Salir
exit
```

## Vía File Manager de Hostinger:
1. Ir a hPanel → File Manager
2. Navegar a: domains/teal-fish-507993.hostingersite.com/public_html
3. Buscar en la parte superior el botón "Git" o "Version Control"
4. Click en "Pull from repository"

## Verificar que funcionó:
1. Abrir: https://teal-fish-507993.hostingersite.com/admin/ajax/search_game_multi.php
2. Ver las primeras líneas (debe decir Version: 2.3)
3. O verificar en Admin → Product Create que ahora muestre 20-40 resultados

## Después de actualizar:
IMPORTANTE: Hacer hard refresh en el navegador
```
Ctrl + Shift + R (Windows/Linux)
Cmd + Shift + R (Mac)
```

O mejor aún:
1. Abrir DevTools (F12)
2. Click derecho en botón refresh del navegador
3. "Empty Cache and Hard Reload"
